# 结构仿写（摘要部分·理工科）

## 功能说明

帮助撰写理工科论文的中文摘要。核心能力是撰写高度凝练、逻辑闭环的学术摘要，准确把握"背景-问题-方法-结果-意义"的学术叙事黄金法则。

## 使用场景

- 撰写理工科论文摘要时
- 需要模仿优秀摘要的结构和语气时
- 希望摘要包含完整的研究信息时

## 输入要求

**必需输入（全部需要）**

1. **参考摘要范文**：一篇优秀论文的摘要（用于模仿其结构和学术口吻）
2. **我的大纲**：论文的整体架构（用于概括研究路径）
3. **我的绪论（片段）**：包含研究背景、现状和主要痛点（用于写摘要的前1/3）
4. **我的实验结果（片段）**：包含具体的实验数据、性能指标或核心结论（用于写摘要的后1/3）
5. **我的系统设计**：主要内容

**重要提示**：实验结果必须含具体数字

**示例格式**：

> 在 Cifar-10 数据集上，准确率比 Baseline 提升了 2.3%，推理速度加快了 15ms。

## 核心任务

### Step 1：结构拆解

分析【参考摘要范文】的叙事逻辑：

- 如何引入背景
- 用什么句式引出痛点
- 如何描述实验结果

### Step 2：内容重组

模仿范文的语气和节奏，将：

- 【我的大纲】
- 【我的绪论】（提取背景和问题）
- 【我的实验结果和系统设计】（提取核心数据和内容）

有机融合，写成属于我的论文摘要

## 约束条件

### 逻辑结构（五段式法则）

1. **背景（Background）**：1-2句，基于【绪论】，简述领域现状
2. **问题（Problem）**：1句，基于【绪论】，指出当前存在的具体缺陷（Gap）
3. **方法（Method）**：2-4句，基于【大纲】，详细描述本文提出了什么模型/算法/框架，以及核心策略
4. **结果（Results）**：2-3句，基于【实验结果】，**必须包含具体数据**。严禁使用"效果良好"这种空话
5. **意义（Conclusion）**：1句，总结本文的学术价值或应用前景

### 风格与规范

- **字数控制**：篇幅控制在 300-500 字之间
- **去机械感**：严禁使用"本文首先...其次...最后"的机械列表
- **客观语气**：使用"本文"作为主语，避免第一人称"我"

### 排版格式（Word 适配）

- **纯净文本**：严禁 Markdown 格式
- **强制空格**：中文与英文/数字/符号之间自动添加空格
- **关键词**：摘要正文结束后，提取 3-5 个核心关键词

## 输出格式

### Part 1：摘要逻辑 [Abstract Logic]

简要说明采用的叙事结构

### Part 2：撰写好的中文摘要 [Drafted Abstract]

### Part 3：关键词列表 [Keywords]
