# 参考文献获取

## 功能说明

识别论文中需要引证的观点，匹配该领域最权威、最原始或最新的真实文献，并生成符合 GB/T 7714-2015 标准的参考文献列表。

## 使用场景

- 需要为论文添加参考文献时
- 需要检查现有引用是否规范时
- 需要获取特定领域的权威文献时

## 输入要求

**必需输入**

- 绪论和理论基础章节内容

## 核心任务

1. **识别引证点**：在文中出现具体算法、学术观点、具体数据或定义的地方，插入引用标记（如 `[1]`）
2. **匹配真实文献**：
   - 对于经典算法/模型（如 CNN, LSTM, YOLO），必须引用原始提出该方法的论文
   - 对于行业现状描述，匹配高引用的综述或近3年的代表性论文
   - 严禁造假：找不到确切文献时，标记为 `[需补充文献]`
3. **生成列表**：在文末输出符合 GB/T 7714 标准的参考文献列表

## 约束条件

### 引用插入规范

- 标记应置于句末标点符号之前
- 引用序号必须全文连续（从 [1] 开始递增）

### GB/T 7714 格式规范

- **期刊 [J]**：`[序号] 主要责任者. 题名[J]. 刊名, 年, 卷(期): 起止页码.`
- **会议 [C]**：`[序号] 主要责任者. 题名[C]//会议名称. 出版地: 出版者, 年: 起止页码.`
- **学位论文 [D]**：`[序号] 主要责任者. 题名[D]. 保存地: 保存单位, 年.`
- **专著 [M]**：`[序号] 主要责任者. 题名[M]. 出版地: 出版者, 年: 起止页码.`

**注意**：欧美作者姓在前（全大写），名在后（缩写），如：`LECUN Y, BENGIO Y, HINTON G.`

### 准确性原则（Hallucination Control）

- 优先使用知识库中确定的真实存在的论文
- 对于不确定的内容，可以使用网络搜索进行核实
- 宁可留白（`[需补充]`），不可编造

## 输出格式

### Part 1：精炼后的正文 [Refined Text]

插入了 `[x]` 引用标记的论文正文（必须完整输出所有正文内容）

### Part 2：参考文献列表 [References List]

对应的 GB/T 7714 参考文献列表

## 注意事项

将生成的文献列表复制到 Google Scholar 或知网核对，确认能搜到且页码/年份正确后再用到论文里

## Prompt 模板

```
# Role
你是一位资深的学术文献检索专家与编辑，精通 GB/T 7714-2015 参考文献著录规则。

# Task
请阅读我提供的【绪论】和【理论基础】章节内容，执行以下操作：
1. 识别引证点：在文中出现具体算法、学术观点、具体数据或定义的地方，插入引用标记。
2. 匹配真实文献：对经典算法必须引用原始论文；对现状描述匹配高引用综述或近3年论文。
3. 生成列表：在文末输出符合 GB/T 7714 标准的参考文献列表。

# Constraints
1. 引用插入规范：标记置于句末标点之前；序号连续递增
2. GB/T 7714 格式规范：严格执行各类文献格式
3. 准确性原则：宁可留白，不可编造

# Input
【绪论与理论章节草稿】：
[在此处粘贴你的论文草稿]
```
