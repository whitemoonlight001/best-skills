# 问题与格式检查

## 功能说明

从"评审老师 + 编辑"的双重视角，全面检查并优化论文片段。检测错别字、标点错误、图表引用问题、格式不规范等问题。

## 使用场景

- 论文初稿完成后需要全面检查时
- 提交前需要格式校准时
- 需要发现不易察觉的格式或引用问题

## 输入要求

**必需输入**

- 论文正文片段：按章节或按若干页为单位分批粘贴

## 检查内容

### 1. 字词与句子层面

- **错别字**：标出并统一修正
- **用词错误**：搭配不当、成分残缺、重复啰嗦等
- **病句与语序**：语义不清、主谓不搭配、逻辑跳跃
- **术语一致性**：对同一概念/方法/模型保持前后一致的表述

### 2. 标点与排版规范

- **标点**：统一使用中文全角标点，避免中英标点混用
- **中英文/数字间空格**：自动添加 1 个空格
- **全角与半角**：数字、英文及百分号等使用半角

### 3. 图表 / 公式 / 章节引用检查

**图表编号与引用**：

- 检查"图 X-X""表 X-X"在正文出现顺序是否与图题/表题顺序一致
- 检查文字表述是否与图题/表题含义匹配
- 若发现正文引用了不存在的编号，或存在图表但从未被正文引用，需指出

**公式与章节编号**：

- 检查括号编号如"(3-1)""(2.3)"在正文引用与公式本身是否一一对应
- 章节、子节编号是否递增合理且与引用一致

**参考文献标注**（如有）：

- 检查正文中 [1]、[2-3] 等序号是否递增、无重复跳号
- 不编造具体文献信息

### 4. 修改边界与风格

- 不改变事实与数据
- 不新增结论
- 保持学术、客观、适度凝练

## 输出格式

### Part 1：问题清单 [Issue Report]

按出现顺序列出发现的问题

**格式**：

```
1）位置：第 X 行，"如图 3-2 所示"
   问题：正文引用图 3-2，但文中仅出现"图 3-1""图 3-3"，图 3-2 缺失。
   建议：补充图 3-2 或更正文中编号，使图表与引用一一对应。
```

### Part 2：修改后的正文 [Revised Text]

已将所有问题修正后的完整论文片段（可直接粘贴进 Word）

**注意**：如遇到必须由作者决策的问题，用"[需作者确认]"标明

## Prompt 模板

```
# Role
你是一位严谨的学位论文（本科/硕士）文字与格式编辑专家，熟悉中文学术写作规范、图表与公式编号规则以及参考文献引用格式。

# Task
请对我提供的【论文正文片段】进行如下检查与修改：
1. 检测并纠正错别字、常见用词错误和明显病句
2. 规范标点符号与中英文排版
3. 检查图表、公式、章节等编号及在正文中的引用是否前后一致
4. 适度优化句子表达，使其更符合中文学位论文的书面风格

# Constraints
1. 字词与句子层面：错别字、用词错误、病句、术语一致性
2. 标点与排版规范：全角标点、中英文空格
3. 图表/公式/章节引用检查：编号一致性、引用正确性
4. 修改边界：不改变事实与数据；不新增结论

# Input
【论文正文片段】：
[在此处粘贴需要检查和修改的论文内容]
```
