# 英转中（论文翻译）

## 功能说明

将英文段落翻译为流畅、易读的中文文本。适合翻译从 PDF 或 Word 复制的英文学术文献。

## 使用场景

- 翻译英文文献或论文片段时
- 需要将英文资料转化为中文论文素材时
- 翻译后需要保持学术精准性时

## 输入要求

**必需输入**

- 英文段落：从 Word/PDF 复制的英文段落

## 约束条件

### 文本清洗与预处理

- **去除干扰项**：翻译时忽略并移除文中出现的引用标记（如 `[1]`, `[12-14]`, `(Smith et al., 2020)` 等），只保留正文内容的翻译
- **修复断行**：如果文本包含 PDF 复制导致的异常换行或连字符（如 `pro- cessing` 被断开），先还原为完整句子再翻译

### 数学与符号处理

- **保留核心符号**：对于文中出现的变量名（如 $x$, $\alpha$, $T_{max}$），直接保留原样
- **公式自然化**：如果文本中包含简单的数学运算描述（如 `a / b`），转化为符合中文阅读习惯的表达

### 翻译原则

- **直译为主，意译为辅**：严格对应原文的逻辑结构，不要进行过度的润色或重写，确保能通过中文反向定位到英文原句
- **学术精准**：对于专有名词，请使用相关学科领域通用的标准中文译名

**示例**：

- `Robustness` → `鲁棒性`（而非 `稳健性`）
- `Transformer` → 视情况保留 `Transformer` 或译为 `Transformer模型`

- **如实反馈**：如果原文句子结构极其复杂或存在歧义，按最可能的逻辑进行直译

### 输出格式

- 只输出翻译后的纯中文文本段落
- 分段输出（如果原文是多段）

```

# Task
请将我提供的【英文段落】翻译为流畅、易读的【中文文本】。

# Constraints
1. 文本清洗与预处理：
   - 去除干扰项：移除引用标记
   - 修复断行：还原被断开的单词

2. 数学与符号处理：
   - 保留核心符号：变量名保持原样
   - 公式自然化：转化为中文表达

3. 翻译原则：
   - 直译为主，意译为辅
   - 学术精准：使用标准中文译名
   - 如实反馈：按最可能的逻辑直译

# Input
[在此处粘贴你从 Word/PDF 复制的英文段落]
```
