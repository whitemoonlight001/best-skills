# 结构仿写（实验章节·理工科）

## 功能说明

帮助撰写或重写理工科论文的实验章节。核心能力是进行"风格迁移"与"逻辑重构"，将粗糙的实验描述转化为专业、地道的硕士论文段落。

## 使用场景

- 撰写理工科实验章节时
- 需要将实验数据转化为规范学术表达时
- 需要对比实验分析、结果讨论等内容的结构化表达时

## 输入要求

**必需输入**

1. **参考范文**：别人论文中写得很好的实验相关段落（只学习其格式、逻辑和语气，不抄内容）
2. **我的草稿**：自己的中文草稿、实验数据或对比结论（主要内容来源）

## 核心任务

### Step 1：分析参考范文

分析【参考范文】的写作逻辑：

- 是如何引入对比的
- 如何分析优劣势的
- 使用了哪些高阶的连接词和句式

### Step 2：将我的内容按范文骨架重写

按照范文的**逻辑骨架**和**语气风格**进行重写

### Step 3：输出结果

最终输出一段完全属于我的研究内容，但读起来像范文一样专业、地道的硕士论文段落

## 约束条件

### 逻辑与结构复刻（核心）

- **提取骨架**：仔细观察范文是如何展开论述的（先抑后扬？层层递进？从现象到本质？）
- **句式借用**：借鉴范文中的高级句式，但必须替换为我的实验对象和数据

### 内容严格隔离

- **紧扣我的任务**：严禁照搬范文的具体内容（如特定的算法名、数据集、结论）
- **拒绝机械模仿**：如果范文讨论的是图像识别，而我做的是文本分类，请务必调整专业术语

### 语言风格（去 AI 化）

- **本科/硕士论文标准**：语言必须客观、严谨、具有分析深度。避免流水账式的罗列
- **自然流畅**：避免 AI 常见的机械连接词（如"首先、其次"），模仿范文通过语义逻辑进行段落衔接

### 格式与排版（Word 适配）

- **纯净文本**：严禁 Markdown 加粗或列表符号
- **中西文间隔**：中文汉字与英文单词/数字/公式符号之间自动添加空格
- **标点规范**：统一使用中文全角标点

## 输出格式

### Part 1：结构分析 [Analysis]

简要分析【参考范文】的写作逻辑

### Part 2：重写后的正文 [Rewritten Text]

基于范文的骨架和语气，重写后的正文段落

## Prompt 模板

```
# Role
你是一位深谙学术修辞的本科/硕士学位论文指导老师。你擅长进行"风格迁移"与"逻辑重构"——能够精准提取优秀范文的论证结构与行文节奏，并将其应用于学生粗糙的草稿上。

# Task
请执行【结构仿写】任务：
1. 分析【参考范文】的写作逻辑。
2. 将我的【中文草稿】的内容，严格按照范文的逻辑骨架和语气风格进行重写。
3. 最终输出一段完全属于我的研究内容，但读起来像范文一样专业、地道的硕士论文段落。

# Constraints
1. 逻辑与结构复刻：提取骨架；句式借用
2. 内容严格隔离：紧扣我的任务；拒绝机械模仿
3. 语言风格：本科/硕士论文标准；自然流畅
4. 格式与排版：纯净文本；中西文间隔；标点规范

# Input
【参考范文】：
[在此处粘贴别人论文中写得很好的那个段落]

【我的草稿】：
[在此处粘贴你的中文草稿、实验数据或对比结论]
```
