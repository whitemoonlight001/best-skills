# 结构化信息提取

## 功能说明

从论文全文或关键章节中提取并概括结构化信息，输出严格符合指定格式的文本，可直接作为「论文答辩 PPT 多页 Draw.io 生成」的 Input 使用。

## 使用场景

- 需要为答辩准备结构化信息时
- 需要将论文内容整理成 PPT 素材时
- 需要提取论文创新点和核心内容时

## 输入要求

**必需输入**

- 论文内容：摘要+目录+各章开头/小结段落或全文

**可选输入**

- 答辩时长：10 分钟 / 15 分钟（默认 10 分钟）
- 配色偏好：学术蓝 / 商务深蓝 / 清新绿 / 极简黑白 / 暖色学术 / 科技深色

## 输出格式

### 必须按以下格式输出

```
【论文题目】：[从论文中提取的完整题目]

【学科方向】：[根据题目和内容推断]

【答辩时长】：[默认 10 分钟]

【配色偏好】：（可选）

【论文结构/目录】：[从论文中提取的章节目录]

【各章核心内容】：
- 第一章（绪论/背景）：[概括]
- 第二章（相关工作/理论基础）：[概括]
- 第三章：[概括]
- ...

【方法章汇报策略】（当存在 2 章及以上讲方法/网络创新时必填）：
- 方法章数量：[1 章 / 2 章 / 3 章 …]
- 章间关系：[递进 / 独立]
- 汇报建议：[合并讲 / 分开讲]

【创新点/贡献】（3–5 条）：
1. [创新点表述]
2. ...

【精选图表】（答辩 PPT 用，严格控制数量）：
- 总配额：10 分钟约 6 张、15 分钟约 8 张
- 配额分配...
```

## 约束条件

1. **忠实原文**：概括基于论文实际内容，不编造、不夸大
2. **精炼**：各章核心内容每条约 20–50 字
3. **创新点**：优先从摘要、结论、各章小结中提取
4. **目录**：保留论文原有章节标题
5. **图表精简**：精选图表须与【方法章汇报策略】联动

## 串联流程

1. **输出结构化信息**，并附说明：「以上内容可直接用于答辩 PPT 生成。」
2. **主动询问用户**：「是否需要基于上述信息生成答辩 PPT？」
3. **若用户确认**：自动调用 `pptgen-drawio` skill 的「论文答辩」模式
