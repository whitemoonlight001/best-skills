# 结构仿写（案例分析/调研实证章节·文科）

## 功能说明

帮助撰写或重写文科论文的案例分析或调研实证章节。核心能力是将原始材料按学术规范组织成逻辑清晰、论证有据的章节，并避免流水账或主观堆砌。

## 使用场景

- 撰写案例分析章节时
- 呈现问卷/访谈调查结果时
- 描述调研数据和分析结果时

## 输入要求

**必需输入**

1. **参考范文**：写得好的案例分析或调研实证章节片段
2. **我的草稿**：案例素材、问卷结果、访谈摘录或调研发现

**建议**：若为问卷/访谈研究，草稿中建议包含数据要点或典型表述

## 核心任务

### Step 1：分析参考范文

分析【参考范文】的写作逻辑：

- 案例如何选取与呈现
- 数据如何与理论/问题对应
- 如何从"现象描述"过渡到"原因/机制分析"

### Step 2：重写我的全部内容（整章重写）

将我的【中文草稿】**全部内容**，按范文的**逻辑骨架**和**学术语气**进行重写

## 约束条件

### 逻辑与结构复刻

- **案例章节**：若范文采用"案例背景 → 具体表现 → 成因/机制分析 → 小结"，保持同类递进；若为多案例，需有可比维度或统一分析框架
- **问卷/访谈**：数据呈现须与 research question 对应；典型表述可引用原文并加引号，后接简要分析
- **与理论挂钩**：实证部分须与前文理论或文献综述形成呼应

### 内容严格基于草稿

- **不得编造数据或案例细节**：所有数字、比例、访谈内容必须来自【我的草稿】
- **可标注占位**：需补充数据或出处处使用 **`[需补充]`** 或 **`[参考文献]`**

### 学术表达（去 AI 化）

- 避免"首先、其次"的机械列表
- 客观陈述：多用"调查显示""受访者指出""案例表明"
- 避免空泛结论

### 格式与排版（Word 适配）

- 严禁 Markdown；中文与英文/数字之间加空格；全角中文标点

## 输出格式

### Part 1：结构分析 [Structure Analysis]

简要分析范文的实证/案例章节逻辑（100 字以内）

### Part 2：重写后的完整正文 [Rewritten Text]

对草稿全部内容重写后的完整案例分析或调研/实证章节正文

```

# Task
请执行【结构仿写】任务：
1. 分析【参考范文】的写作逻辑。
2. 将我的【中文草稿】全部内容，按范文的逻辑骨架和学术语气进行重写。
3. 输出完整的、属于我的研究、读起来像范文一样专业的实证/案例章节正文（整章重写）。

# Inputs
1. 参考范文：写得好的案例分析或调研实证章节片段

# Constraints
1. 逻辑与结构复刻：案例章节；问卷/访谈；与理论挂钩
2. 内容严格基于草稿：不得编造；可标注占位
3. 学术表达：去 AI 化；客观陈述
4. 格式与排版：Word 适配

# Input
【参考范文】：
[在此处粘贴]

【我的草稿】：
[在此处粘贴]
```
